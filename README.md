# 学習アニメーション

小学生向けの解説動画のシリーズ（算数・国語）。台本から映像・声・効果音までコードで作っています。

公開ページ: https://sanny114.github.io/sansu-animation/

| # | タイトル | 尺 | フォルダ |
|---|---|---|---|
| 算数 第1作 | 2・4・8でわると、小数でかならずわり切れる | 2分34秒 | `waru-248/` |
| 算数 第2作 | 同じ量、いろいろな表し方（整数・分数・小数） | 3分40秒 | `bunsu-shosu/` |
| 国語 第1作 | 気持ち探偵になろう！（物語の気持ちの読み取り） | 1分10秒 | `kimochi-tantei/` |

## つくり方

1. 台本（場面ごとの映像・セリフ・テロップ、画面の共通ルール）
2. ナレーション合成（算数はedge-ttsで単語ごとの読み上げ時刻を取得、国語はGemini TTSで1行ずつ）
3. HTML Canvas で「時刻 t の画面」を関数として描き、Playwright で連番PNGに書き出し
4. 効果音・BGMを numpy で合成し、ffmpeg で 60fps の MP4 に

制作ソース（HTML・音・ナレーションのスクリプト）は手元の作業フォルダにあり、このリポジトリには完成動画と紹介ページだけを置いています。
