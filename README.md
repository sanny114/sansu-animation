## ファイル構成

```
index.html          一覧ページ（教科ごとに分けて表示。子どもがタップして選ぶ）
<作品フォルダ>/
  index.html        作品ページ（動画・ねらい・場面・主な場面・つくり方）
  *.mp4             完成動画（1920×1080 / 60fps）
  poster.jpg        サムネイル（一覧のカードと動画の表紙に使用）
  storyboard.png    主な場面の一覧
.nojekyll           GitHub Pages でそのまま配信するための空ファイル
```

どのページもスマホ（幅320px〜）・タブレット・PCで崩れずに見られることを確認しています。

## 作品を追加するとき

1. 新しいフォルダを作り、`index.html`・動画・`poster.jpg`・`storyboard.png` を置く（既存の作品フォルダの `index.html` をひな形にする）
2. 一覧ページ `index.html` の該当する教科の `<div class="grid">` にカードを1枚足す
   - 新しい教科のときは `<section class="subject …">` ごと追加し、上部の教科ボタン（`.jump`）にも足す
   - 教科ボタンの「○本」の数も更新する
3. この README の動画一覧に行を足す

## つくり方

1. 台本（場面ごとの映像・セリフ・テロップ、画面の共通ルール）
2. ナレーション合成（算数は edge-tts で単語ごとの読み上げ時刻を取得、国語は Gemini TTS で1行ずつ）
3. HTML Canvas で「時刻 t の画面」を関数として描き、Playwright で連番PNGに書き出し
4. 効果音・BGMを numpy で合成し、ffmpeg で 60fps の MP4 に

制作ソース（HTML・音・ナレーションのスクリプト）は手元の作業フォルダにあり、このリポジトリには完成動画と紹介ページだけを置いています。
